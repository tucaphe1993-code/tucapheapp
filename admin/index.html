Về hệ thống

Tú Cà Phê Admin — hệ thống quản trị nội bộ: sản phẩm, đơn hàng, khách hàng, thư viện nguyên liệu, công thức pha chế & giá vốn, công cụ tính giá bán và điểm hoà vốn.

Phiên bản demo — dữ liệu lưu cục bộ (localStorage) trên trình duyệt này, chưa kết nối backend/Lark Base thật.

🏷️ Bản gốc Tú Cà Phê

Hệ thống này do Tú Cà Phê tự xây dựng riêng (không dùng chung template với ai khác), nên không có "bản gốc" để đối chiếu như các nền tảng no-code.

Nếu cần khôi phục dữ liệu về trạng thái ban đầu, dùng nút ↺ Khôi phục gốc. Nếu cần lưu trữ/chia sẻ dữ liệu, dùng 💾 Lưu vào file để tải file backup, và 📁 Nạp từ file khác để nạp lại.
